# AMIO Project

Краткий запуск:

1) Сборка фронтенда:
   - `cd frontend`
   - `npm install`
   - `npm run build`

2) Запуск сервисов:
   - `cd ..`
   - `docker compose up --build`

Открыть сайт: `http://localhost:8000`
